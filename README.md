# AgriRoute — Real-Time Crop Transportation Optimization System

A web-based AI logistics platform connecting farmers and drivers 
for optimized crop transportation.

## 🌐 Live Demo
https://agri-route-8gvr.vercel.app

## 🛠️ Tech Stack
- JavaScript
- Leaflet.js
- CARTO Maps
- Vercel

## ✨ Features
- Role-based dashboards for farmers and drivers
- Real-time map route visualization across Telangana
- Delivery creation, tracking and status updates
- Projected 25-30% reduction in crop spoilage
